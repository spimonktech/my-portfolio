About

The engineer
behind the interface.

I'm a Flutter developer currently building enterprise mobile systems at Riota IoT Solutions in Chennai. My focus is the gap between design and reality — taking well-thought-out interfaces and wiring them to backends that don't break at scale.

My current main project, the Cloud Admin Tracker, replaced a fragile email-based request system with a full enterprise Flutter PWA — covering everything from PO mapping to user onboarding and cloud resource management.

I care deeply about architecture clarity, RBAC patterns, clean API contracts, and the kind of UX that makes complex workflows feel effortless. My stack spans Flutter, Dart, Firebase, Node.js, MySQL, and Python — with Figma in between for when design decisions need to be locked before a line of code is written.
